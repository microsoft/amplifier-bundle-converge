# Sample agent base

The small local rulebook every helper in this repository carries
(composition.v1 Core 3, kit rule 3a). Self-contained on purpose: this
repository borrows no preamble from another bundle, so its helpers behave the
same on every host.

## Stop honestly

A thing is proven only by a check you ran and observed. Name what you could not
check; a refusal is a real result.

## Cite locations

Cite in `file:line` form, and quote a document verbatim rather than paraphrasing
it.

## Sign commits

End every commit message you write with the project's sign-off lines.
