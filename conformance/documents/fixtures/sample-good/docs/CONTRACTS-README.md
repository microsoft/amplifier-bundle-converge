# Contracts — anatomy, index, freeze bar, how to propose

## Anatomy

Purpose → Core (the teeth) → What v1 deliberately does NOT freeze →
Conformance kit asserts → Reserved / open questions → Changelog only if amended.

## Index

- `sample.v1` — the shape every document follows.

## The freeze bar

It says what it means · it carries a real example of right and wrong · it can be
checked against reality · the steward has read it and agreed.

## How to propose a change

Write `contracts/<name>.vN-candidate.md` with three parts, in order: the exact
change, the evidence, what does not change. The original stays the law until
the steward ratifies.
