Verify and trust this server

This preview serves itself over HTTPS with a certificate signed by a small local certificate authority it created on this machine — not one any browser already trusts. Encryption alone does not prove that you reached the right server.

Option A — read setup information only

If you click through the certificate warning to reach this public setup page, do not enter your machine password. An untrusted certificate can belong to an impersonator. Use this page only to obtain the public CA certificate, then verify its fingerprint through a trusted channel before installing it.

Option B — trust the CA once, no more warnings

Download the CA's public certificate and add it to your browser or operating system's trust store. This is the same certificate every connection to this server is ultimately signed by, so trusting it once covers every future renewal — you will not need to repeat this when the leaf certificate is reissued.

Browsing after the warning, vs. an installed app

Clicking through the warning is only for this public setup information, not for signing in with a machine password. It is not enough for installing this app as its own icon (a PWA): most browsers refuse to install a site as an app while its certificate is untrusted. If you want the installed-app experience, trust the CA first (Option B above), then install.
