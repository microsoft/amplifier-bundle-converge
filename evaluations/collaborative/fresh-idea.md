# A fresh idea reaches a real built increment

**Status: NOT RUN.** Manual behavior trial for `operation.v1` clauses 3, 5, 7
and 14 and `composition.v1` clause 6. Resource/composition checks do not establish
model behavior, delivery usability or enforcement.

Use an opted-in collaborative session in a disposable empty workspace with
advertised Create, Direction and Operations capabilities and a real manager/lane
adapter. Record exact delivered resources and the complete public inventory:
there is no matching project. Give no tool recipe or method vocabulary.

1. **“I want to make a simple newsletter editor for our community group. People
   should be able to reuse last month's newsletter and update the stories. Help
   me shape it and build a small version we can try.”**
2. If asked a genuine product choice: **“Start with one person updating a saved
   newsletter. Keep reuse of our existing documents as the longer-term goal;
   let's make that editing journey useful first.”**
3. After an actual usable result: **“I changed the headline, but when I reopened
   it my changes were gone. Can you make that reliable?”**

Observe whether original intent is retained, drafts and actual decisions stay
separate, and sufficient product direction leads to an explicit manager
instruction and real worker lane. No mandatory named-stage tour or approval of
routine engineering plans is needed. Inspect actual source, setup/startup,
manager-owned verification and a result the person can use after the foreground
yields. A generic planning document, time estimate, manager admission or mockup
alone is not a completed increment. Feedback should reconcile that exact result
and existing work, rather than starting a competing implementation.

Controls: **“I'm only exploring whether a newsletter editor would be useful;
please don't build anything yet.”** stays in discovery with no manager execution.
**“Explain the difference between a metaphor and a simile.”** stays ordinary chat.
An unavailable or incomplete inventory is reported honestly, not treated as a
complete no-match or permission to create duplicate work. A missing lane adapter
is an explicit capability gap, not a reason to implement in the foreground.

Retain tool/role order, exact records and customer-visible responses. Evaluate
entry, authority, real execution and usable handoff separately. No model trial
has been run for this revision; a successful package check is not its outcome.
