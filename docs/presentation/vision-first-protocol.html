How we've been working with agents — and the rules that keep it honest.

August 2026 · Distilled from three projects' session evidence

The problem

Vision documents decay in silence.

“Still called the north star, but cited by zero current documents.”

audit of cortex's March 2025 vision docs, August 2026

A vision nobody reads is worthless. And agents make it worse: they move fast, so without a binding steering artifact they move fast in a direction nobody chose.

The idea

Negotiate the contract. Derive the work.

  • 01Vision stops being prose to admire. It becomes a small set of frozen, machine-checkable statements of what matters.
  • 02Work is derived, never invented. The gap between repo reality and the contract is the backlog.
  • 03Direction changes land in the contract first — before any implementation.

The owner and the orchestrator meet at the contract level. Autonomous lanes close the gaps below it.

The stack

Five layers, each converging at a different rate.

LayerArtifactConverges?
Strategythe negotiation loop itselfnever — permanently open
Visiondocs/VISION.mdslowly, by ratified amendment
Contractscontracts/<seam>.v<N>.mdfrozen between amendments
Ledgerconformance rows, one per clausecontinuously re-derived
Lanesbriefs, worktrees, DONE.mddisposable

The human occupies the Strategy seat. Everything below it exists to make that seat cheap.

Scope

“If this changed silently, who breaks?”

If the answer names anyone outside this repo — a sibling client, another team, an automation reading a file format — it's a seam, and it gets a contract. If it doesn't, it gets tests. We don't manufacture contracts for repos with no seam.

A feature that exists on one platform and nowhere else is either convergent behavior that belongs in the contract, or it is debt. There is no third option.

cortex-core · client-experience.v1

The loop

Eight phases and one standing audit.

  • 0 INVESTIGATENever negotiate from memory. Disposable explorers gather evidence first.
  • 1 NEGOTIATEOwner + orchestrator at decision level. Minutes, not documents.
  • 2 ENCODEVision and contracts committed before any implementation.
  • 3 SEEDFirst reconciliation: repo vs. contract populates the ledger.
  • 4 QUEUELedger rows become tracker items with clause-quoting acceptance criteria.
  • 5 EXECUTEAutonomous lanes claim and close items, worktree-isolated.
  • 6 MERGE+VERIFYEvery verdict promoted only by its own artifact check.
  • 7 CLOSEFreeze-bar report. Residuals named honestly.
  • RECONCILEStanding, not a phase: conformance runs on every merge and on schedule. Drift in either direction files a ledger row.

RECONCILE stopped being a skippable phase for a measured reason: the one tracker bypass we caught happened “because reconcile wasn't mechanized.” Anything that depends on remembering to run it will eventually not run.

Evidence / what broke

The rules came from measured failures, not opinions.

What we measuredThe rule it produced
Monitors reported PASS for work that had not happened — twice, in independent sessions.
A self-report is never proof. Promotion to proven requires an artifact check the orchestrator runs itself.
Artifacts inherited from the fork point were credited as a lane's own work. The #1 false signal.
Check provenance — commit and mtime — before crediting any artifact.
A live session pane and a green health endpoint told us nothing about whether work landed.
Completion is knowable only from git artifacts. Never from session liveness.
Invariants

Five rules. No exceptions negotiated yet.

  • 01Vision is never status. A page that must be edited when a feature ships is a status report wearing a vision's name.
  • 02A self-report is never proof. An agent's verdict is a raw observation until an artifact check confirms it.
  • 03Amendments are CANDIDATE files, never direct edits. Anyone may propose; only the owner ratifies, with the literal word.
  • 04Freeze requires a discriminating example. Prose alone freezes nothing.
  • 05A missing artifact is a real result. N/A with a reason beats fabricated compliance. The enemy is the successful-looking run that did nothing.

The Freeze Bar — all four, owner stamps only: the spec · a conformance kit with a discriminating good/bad fixture pair · one real implementation passing it · a worked example.

The payoff

Four things reach the human.

  • 01Ratifying vision and contract changes, including FROZEN stamps.
  • 02Irreversible or destructive calls.
  • 03Verification only a human or a device can perform.
  • 04Priority and kill decisions.

Anything else that reaches the owner is filed as a defect — against the protocol.

You spend attention at the contract layer. The system runs below it.
