# Amplifier Converge — the deck

`amplifier-converge.html` is one self-contained file. No server, no network, no build.

**Open it.** Double-click the file, or `open`/`xdg-open` it. Everything (CSS, JS, images) is inline.

**Present it.** `→` `←` `Space` `PageUp/Dn` move; `Home`/`End` jump; tap or click (left 30% goes back).
`T` toggles the 6-slide short version (also offered on slide 2); `N` toggles speaker notes — one plain
narration sentence per slide; `Esc` leaves either. A progress bar and `n / 18` counter sit on screen.
Deep-link a slide with `#7`. Reduced-motion is respected; 18 slides run about six minutes.

**Assets.** The five hero images are AI-generated, textless illustrations made for this deck
(`assets/hero-*.png` masters; the embedded copies are the `.jpg` derivatives). Every other visual is
hand-built inline SVG/CSS. The UX mockup screenshots were **not** used: they carry an older wordmark
and superseded lifecycle vocabulary this deck must not show. `verify.py` re-runs every check, rewrites
`screenshots/` (headless Chromium via Playwright); `verify-report.json` is its last run.
